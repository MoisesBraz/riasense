# Diagramas

Os diagramas como fonte HTML/SVG (ADR-0026). Abrem-se no browser, sem pedidos externos: as fontes (Inter e Geist Mono) vêm do sistema, e o PNG da Figura 1 do relatório foi desenhado com a Inter.

| Ficheiro | O quê |
| --- | --- |
| `riasense-4-pilares.html` | Os 4 pilares sobre o Living Lab de Aveiro, a versão completa, com título, descrição e legenda (③ a 3 h, caixa do IT «proposta: no painel que o IT já usa») |
| `riasense-4-pilares-relatorio.html` | A mesma figura em formato largo (1000 × 420) e letra maior, para se ler a 451 pt de largura. É a Figura 1 do relatório de 18/11 ([`entregaveis/2026-11-18-relatorio/`](../../entregaveis/2026-11-18-relatorio/texto.md)) |

O PNG do relatório (3000 × 1260) e as exportações do Figma estão no Nextcloud (`04-design/diagramas/`), porque são binários (ADR-0026). Para o gerar de novo, abre o HTML do relatório e exporta só o diagrama, sem margens, a 3000 px de largura.
